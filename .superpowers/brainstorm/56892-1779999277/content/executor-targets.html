Which deployment executor targets should this support?

This shapes the adapter layer. You can pick multiple — but each adds complexity to the domain model.

A

SSH + Shell

Connect to remote server, run docker compose up / shell scripts. Simplest executor. Good for VPS, bare metal.

Port: SSHExecutorAdapter

B

Docker API

Talk directly to Docker daemon via HTTP socket. Pull images, run containers, inspect logs. No SSH needed.

Port: DockerApiAdapter

C

Kubernetes

Apply manifests via k8s API. Rollouts, rollbacks, health checks via pod status. Most complex adapter.

Port: KubernetesAdapter

D

Local Process

Run commands on same machine as Symfony (dev/testing). Useful for CI runners or single-server setups.

Port: LocalProcessAdapter
